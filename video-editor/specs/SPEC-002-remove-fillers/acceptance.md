# SPEC-002 인수 기준

테스트 영상은 ffmpeg lavfi로 생성하고, Whisper 호출(`pages.remove_fillers.api.transcribe`)은 모킹한다.
- `speech.mp4`: 6초, 1초 GOP, 톤 오디오
- `noaudio.mp4`: 3초, 오디오 트랙 없음
- 모킹 전사 결과:

| 단어 | start | end | 비고 |
|------|-------|-----|------|
| 안녕하세요 | 0.2 | 1.0 | |
| 이제 | 1.5 | 1.8 | 앞 간격 0.5 → 간투사 |
| 시작합니다. | 1.9 | 2.6 | |
| 그래서 | 2.65 | 2.9 | 문장 시작 → 간투사 |
| 진짜 | 2.95 | 3.5 | |
| 좀 | 3.55 | 3.7 | 문장 중간, 간격 0.05 → 유지 |
| 어려워요. | 3.75 | 4.5 | |

- 사전: `이제`, `그래서`, `좀`
- 제거 구간: [1.4, 1.9], [2.6, 2.95] → 유지 [0, 1.4] + [1.9, 2.6] + [2.95, 6] + padding 0.05 × 2 = **5.25초**

## 시나리오

### AC-1 간투사 제거 (재인코딩, 기본) — REQ-E2, E4~E8
- **When** 기본 옵션으로 실행하면
- **Then** 결과 길이는 5.25초 ±0.1초이고, 간투사 목록과 원본/결과/단축 시간이 출력된다

### AC-2 dry-run — REQ-E9
- **When** `--dry-run`으로 실행하면
- **Then** 출력 파일이 생기지 않고, 간투사 2개 표(판정 근거 포함), 예상 길이 00:00:05.25, 단축 00:00:00.75가 출력된다

### AC-3 기본 출력 파일명 — REQ-E10
- **Then** 같은 폴더에 `speech_no_fillers.mp4`가 생긴다

### AC-4 copy 모드 — REQ-E11
- **When** `--no-reencode`로 실행하면
- **Then** 출력 파일이 생기고, 결과가 길어질 수 있다는 경고가 출력된다

### AC-5 간투사 없음 — REQ-E15
- **Given** 사전에 전사 결과에 없는 단어만 있을 때
- **Then** "간투사 없음"이 출력되고 출력 파일은 원본과 바이트 단위로 같다

### AC-6 사전 없음 — REQ-E12
- **Then** 종료 코드 1, "fillers.txt를 생성하고 간투사를 한 줄에 하나씩 입력하세요"

### AC-7 API 키 — REQ-E13
- **Given** `OPENAI_API_KEY` 미설정 → 종료 코드 1, `OPENAI_API_KEY` 안내, Whisper 미호출
- **Given** `--api-key` 지정 → 그 키로 호출

### AC-8 Whisper 실패 — REQ-E14
- **Then** 종료 코드 1, "Whisper API 호출 실패", 출력 파일 없음

### AC-9 오디오 없음 — REQ-E16
- **Then** 종료 코드 1, "오디오 트랙"

### AC-10 임시 파일 정리 — REQ-S1
- **Then** 성공/실패와 관계없이 `remove_fillers_*` 임시 디렉터리가 남지 않는다

### AC-11 입력 덮어쓰기 방지 — REQ-N1
- **Then** 종료 코드 1, 입력 파일 불변

### AC-12 한글/공백 경로
- 모든 시나리오를 `테스트 폴더/` 아래에서 실행한다

### AC-13 전사 캐시 — REQ-S2
- **When** `--dry-run` 후 같은 파일로 실제 실행하면
- **Then** Whisper는 1번만 호출되고 "저장된 전사 결과"가 출력된다

### AC-14 ffmpeg 미설치 / AC-15 subprocess 실패 — REQ-E16
- SPEC-001 AC-8, AC-9와 같음 (모킹)

## 엣지 케이스 (단위 테스트)
- 구두점이 붙은 단어(`이제,`) 정규화
- 세그먼트 토큰 수 ≠ 단어 수 → 세그먼트 양끝만 경계
- 세그먼트가 없으면 전체 첫/마지막 단어만 경계
- 연속된 간투사 제거 구간 병합
- 영상 시작/끝 클램프, Whisper 타임스탬프가 겹칠 때 구간 역전 방지
- 5분 초과 오디오 청크 분할과 타임스탬프 오프셋
- 청크 경계: 5분 지점 직전 60초 안 무음이 있으면 5분에 가장 가까운 무음 가운데, 범위 밖 무음은 무시, 없으면 5분 지점
- 5분 이하 영상은 무음 감지(ffmpeg) 없이 청크 1개
- prompt: 첫 청크는 없음, 이후 청크는 직전 청크 텍스트 마지막 100자
- 중간 청크 전사 실패 시 오류 메시지에 청크 번호 포함
- 캐시: 왕복, 원본 변경 시 무효, 깨진 파일 무시
- Whisper 래퍼: 요청 파라미터(prompt 유무), `max_retries=4`, 예외 변환, 25MB 초과 사전 차단
- 무음 감지(`shared/api/silence.py`): 로그 파싱은 SPEC-001 단위 테스트를 이동해 유지

## 품질 게이트

- 인수 테스트는 ffmpeg가 있는 환경에서 skip 없이 통과
- `src/shared`는 `src/pages`를 import하지 않는다
